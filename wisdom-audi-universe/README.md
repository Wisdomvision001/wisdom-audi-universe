# Wisdom Audi — Digital Universe

A fresh, responsive portfolio concept based on the uploaded Wisdom Audi Universe reference. This is a new implementation, not an edit of the old portfolio.

## Run locally
No build step is required:
1. Extract the ZIP.
2. Open `index.html` in a browser, or use VS Code Live Server for the best local workflow.

## Before publishing
- Replace `wisdom.audi@example.com` in `index.html` with your real email address.
- Verify every repository link and add live demo URLs only where the projects are actually deployed.
- Review role titles and project descriptions for accuracy.
- The project visuals are custom CSS-built interface illustrations, not screenshots of the live applications. Replace them with real screenshots when ready.
- Google Fonts are loaded from the web; system fallbacks are included.

## Design direction
- Cinematic cosmic entrance with a lone traveler and eclipse-like planet
- Premium dark graphite / blue-gray palette with restrained mint accents
- Four featured projects with custom visual compositions
- About, principles, experience, toolkit, and contact sections
- Responsive mobile navigation, reveal motion, reduced-motion support

## Files
- `index.html` — page content and structure
- `styles.css` — visual system and responsive layouts
- `script.js` — navigation, subtle cursor glow, reveal animations
